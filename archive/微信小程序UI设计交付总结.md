## 🎨 11个页面快速导航

### 1️⃣ 首页 (index)

**用途**：应用入口，展示热搜、推荐商品  
**关键元素**：
- 搜索栏（高 48px）
- 分类导航（横向滚动）
- Banner 轮播（16:9，3秒自动）
- 热搜榜（TOP 6）
- 推荐商品（横向卡片）

**UI 要点**：
```
[搜索栏················]
[分类··················]滚动
[··图片轮播············]
🔥 热搜榜
[1] iPhone 15 Pro Max
[2] iPad Air
...
推荐好物
[卡片][卡片][卡片][卡片]
```

---

### 2️⃣ 搜索页 (search)

**用途**：快速搜索商品  
**关键元素**：
- 搜索框 + 语音输入
- 搜索历史
- 热搜榜单
- 推荐搜索词

**状态**：
- 初始状态：空搜索框 + 历史 + 热搜
- 搜索中：加载中指示
- 搜索后：跳转到搜索结果页

---

### 3️⃣ 搜索结果页 (searchResults)

**用途**：展示搜索结果  
**关键元素**：
- 搜索词条（可编辑）
- 筛选面板（弹窗）
- 排序选项
- 商品列表（无限加载）

**筛选维度**：
- 价格区间（滑块）
- 平台多选
- 品牌多选
- 评分

---

### 4️⃣ 商品详情页 (productDetail)

**用途**：展示商品完整信息  
**关键元素**：
- 图片轮播（支持 3-10 张）
- 基本信息（标题、评分、价格）
- 价格对比表（4-6 个平台）
- 价格走势图（3 个月）
- 用户评价（前 3 条）

**必有操作**：
- 收藏按钮（❤️）
- 分享按钮
- 设置降价提醒
- 购买（跳转外部）

---

### 5️⃣ 商品对比页 (comparison)

**用途**：多商品参数对比  
**关键元素**：
- 商品卡片选择（支持 2-4 件）
- 参数对比表
- 平台价格对比
- 分享对比链接
- 购买链接

---

### 6️⃣ 我的收藏页 (favorites)

**用途**：管理收藏商品  
**功能**：
- 查看收藏列表
- 批量删除 / 对比
- 设置降价提醒
- 快速购买跳转

**列表字段**：
- 商品图片
- 商品名称
- 价格范围
- 降价幅度
- 操作按钮

---

### 7️⃣ 降价提醒页 (priceAlerts)

**用途**：管理价格提醒  
**功能**：
- 查看所有提醒
- 过滤已触发 / 未触发
- 设置 / 修改目标价格
- 删除提醒
- 触发通知

**提醒状态**：
- 绿色标记：已触发，价格已到达
- 黄色标记：即将触发
- 灰色标记：未触发

---

### 8️⃣ 浏览历史页 (history)

**用途**：查看浏览过的商品  
**功能**：
- 查看浏览历史
- 按日期分组（今天、昨天等）
- 清空历史
- 再次浏览快速购买
- 商品对比

---

### 9️⃣ 分类页 (category)

**用途**：分类浏览商品  
**设计**：
- 左侧：分类树（可滚动）
- 右侧：子分类列表
- 支持搜索分类

**交互**：
- 点击分类高亮
- 支持横竖分类切换

---

### 🔟 用户中心页 (userCenter)

**用途**：用户账户管理  
**功能菜单**：
- 📌 我的收藏
- 📊 降价提醒
- 🕐 浏览历史
- ⭐ 我的评价
- ⚙️ 设置
- 📋 关于我们
- [退出登录]

---

### 1️⃣1️⃣ 登录页 (login)

**用途**：用户认证  
**登录方式**：
1. 微信一键登录（优先）

## 📐 响应式适配

### 屏幕适配范围

| 屏幕宽度 | 设备 | 处理方式 |
|---------|------|---------|
| 280-320px | 超小屏 | 1:1 等比缩放 |
| 320-375px | iPhone 6-8 | **基准方案** |
| 375-414px | iPhone X 等 | 等比缩放 |
| > 414px | iPad / 大屏 | 增加间距 |

### 关键断点处理

```scss
// 超小屏 (< 320px)
$screen-xs: 320px;
.container {
  padding: 12px;  // 减少边距
  font-size: 13px;  // 稍微缩小
}

// 标准屏 (320-375px)
$screen-sm: 375px;
.container {
  padding: 16px;  // 标准边距
}

// 大屏 (> 375px)
$screen-lg: 414px;
.container {
  padding: 20px;  // 增加边距
  max-width: 600px;  // 限制宽度
}
```

## 📋 使用本设计方案的步骤

### 步骤 1️⃣：理解设计系统

1. 读完"微信小程序UI设计方案.md"的设计系统部分
2. 记住主要（3 个）颜色代码：#FF6B35、#004E89、#50C878
3. 了解间距系统：4px、8px、12px、16px、24px、32px

### 步骤 2️⃣：输出高保真原型

使用 Figma / Sketch 或 Adobe XD，根据本方案输出高保真原型：
- 创建 11 个页面的设计稿
- 使用统一的组件库
- 标注尺寸和间距
- 导出切图资源

### 步骤 3️⃣：前端项目初始化

```bash
# 创建 uni-app 项目
npm create vite@latest ycg-miniprogram -- --template vue

# 或使用 HBuilderX 新建
# 选择 uni-app，框架选 Vue 3

# 安装依赖
cd ycg-miniprogram
npm install
```

### 步骤 4️⃣：搭建样式系统

1. 复制 SCSS 变量到 `src/styles/variables.scss`
2. 配置全局样式 `src/styles/common.scss`
3. 建立 SCSS 混入文件 `src/styles/mixins.scss`

### 步骤 5️⃣：开发核心组件

按照"小程序UI开发实现指南.md"开发顺序：
1. Button、Input、Modal 等基础组件
2. ProductCard、PriceLabel 等业务组件
3. 组件库文档和测试

### 步骤 6️⃣：开发页面

按优先级顺序开发 11 个页面：
```
第 1 周：首页 + 搜索页
第 2 周：搜索结果页 + 商品详情页
第 3 周：用户功能页 (收藏、提醒、历史)
第 4 周：其他页面 + 登录
```

### 步骤 7️⃣：集成测试

1. 真机测试 (iOS / Android)
2. 不同屏幕尺寸测试
3. 网络条件模拟
4. 性能指标检查

### 步骤 8️⃣：发布上线

1. 灰度发布（10% → 50% → 100%）

## 💡 常见设计问题 Q&A

### Q: 价格显示应该保留几位小数？

**A:** 统一保留 2 位小数，格式：¥XXX.XX  
示例：¥5999.00、¥599.99

### Q: 商品图片加载失败怎么处理？

**A:** 显示通用占位图，灰色背景 + 图片 icon

### Q: 多个平台价格一样怎么显示？

**A:** 仍正常显示，用户可根据卖家评分等选择

### Q: 底部 Tab 栏固定吗？

**A:** 是的，sticky 固定，始终可见

### Q: 黑色模式支持吗？

**A:** 当前版本不支持，可作为 v2 功能添加

### Q: 国际化 (多语言) 支持吗？

**A:** 当前版本仅中文，多语言可作为 v2 功能

### Q: 动画性能会不会很差？

**A:** 使用 CSS 动画 / GPU 加速，性能有保证  
避免过度动画，保持 60fps

## 📱 微信小程序特殊处理

### 小程序特有限制

```
1. 单个包大小限制         2 MB
   → 使用代码分割、图片压缩

2. 图片加载限制           域名必须备案
   → 使用 CDN，配置跨域

3. 样式限制               不支持某些 CSS
   → 避免使用 @import、伪元素过多

4. API 限制               某些浏览器 API 不支持
   → 使用 uni API 替代

5. 安全限制               必须使用 https
   → 所有请求都要 https

6. 频率限制               API 调用有速率限制
   → 实现缓存、防抖、节流
```

### 小程序优化建议

```
1. 图片优化
   ✓ 商品主图 < 200KB
   ✓ 使用 WebP 格式 (兼容性好)
   ✓ 使用图片懒加载

2. 包体积优化
   ✓ 代码分包 (分包加载)
   ✓ 树摇 (Tree Shaking)
   ✓ 移除未使用的代码

3. 首屏加载优化
   ✓ 预加载关键数据
   ✓ 使用骨架屏
   ✓ 目标首屏 < 2s

4. 运行时优化
   ✓ 虚拟列表 (长列表优化)
   ✓ 防抖/节流 API 调用
   ✓ 缓存策略
```
