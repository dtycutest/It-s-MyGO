# "一次买够"网购比价平台

## 项目概述

**项目名称**：一次买够网购比价平台
**项目类型**：微信小程序 + 后端 API + 爬虫系统
**核心价值**：一次搜索，全面比价

### 项目背景与目标

在网购日益普及的今天，消费者通常需要在京东、淘宝、天猫等多个电商平台之间反复搜索、比价，过程繁琐且耗时。"一次买够"网购比价平台旨在解决这一痛点，提供一站式的跨平台商品比价服务。

用户只需在小程序中输入商品关键词，系统即可同时展示来自京东和淘宝的同款商品及其价格，帮助用户快速找到最具性价比的购买渠道，真正实现"一次搜索，全面比价"。

### 核心功能

1. **跨平台商品聚合搜索**
   - 支持关键词搜索，同时检索京东和淘宝平台的商品数据
   - 搜索结果按相关性排序，支持按价格、销量等维度切换
   - 提供热搜词提示和搜索建议

2. **商品详情与多平台比价**
   - 展示商品的详细信息（图片、标题、描述）
   - 以卡片形式对比不同电商平台的同款商品
   - 清晰标注各平台的价格、店铺名称、销量、库存状态
   - 自动标记最低价平台（最优价标签）
   - 支持复制商品链接，方便跳转到对应平台购买

3. **微信授权登录**
   - 支持微信一键登录（通过微信 jscode2session 接口）
   - 保留模拟登录入口，方便开发调试
   - 基于 JWT 的认证机制，Token 自动刷新

4. **用户中心**
   - 个人资料展示（昵称、头像）
   - 收藏管理：收藏感兴趣的商品，随时查看和取消
   - 浏览历史：自动记录浏览过的商品，时间轴展示，去重处理
   - 降价提醒：设置目标价格，当商品价格低于目标价时自动标记提醒

5. **个性化推荐**
   - 基于用户收藏和浏览历史的品类偏好分析
   - 优先展示用户感兴趣品类的商品
   - 优先展示有跨平台比价关系的商品
   - 支持"换一批"随机刷新，保持推荐的新鲜感

6. **数据采集与维护**
   - 爬虫系统每天从京东和淘宝采集商品数据
   - 经数据清洗、去重后存入 MySQL 数据库
   - 后端从数据库加载数据并通过 API 提供给前端

## 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端 | uni-app (Vue 3 + Pinia + TypeScript + SCSS) | 编译为微信小程序，一套代码多端复用 |
| 后端 | Python 3.12 + FastAPI + Uvicorn | 高性能异步 Web 框架，自动生成 API 文档 |
| 数据库 | MySQL 8.0 (PyMySQL) | 存储商品、用户、收藏、历史等数据 |
| 认证 | JWT (python-jose) | 无状态认证，Token 过期自动刷新 |
| 爬虫 | Scrapy + Playwright | 真浏览器渲染，绕过反爬检测 |
| 内网穿透 | cpolar | 真机扫码预览时使用，将本地服务暴露到公网 |

### 各部分职责

**爬虫系统 (crawler/)**
- 从京东、淘宝采集商品信息（标题、价格、图片、店铺、销量等）
- 使用 Playwright 真浏览器渲染，模拟真实用户行为
- 数据清洗去重后写入 MySQL
- 每天定时运行，持续更新数据库中的商品数据

**后端 API (backend/)**
- 从 MySQL 加载商品数据（也支持内置种子数据作为降级方案）
- 提供 33 个 RESTful API 接口，覆盖搜索、商品、用户、收藏、历史、提醒等功能
- JWT 认证 + 微信 jscode2session 登录对接
- 基于用户行为的个性化推荐算法
- 自动生成 OpenAPI 3.0 接口文档（`/docs`）

**前端小程序 (frontend/)**
- 微信小程序界面，用户直接交互层
- 通过 HTTP 调用后端 API 获取和提交数据
- 不直接访问数据库或爬虫
- 详细的架构、组件、API 说明见 [frontend/README.md](ycg-project/frontend/README.md)

## 快速开始

### 环境要求

- Python >= 3.12
- Node.js >= 18
- MySQL 8.0（爬虫和完整功能需要，后端可使用内置种子数据）

### 后端启动

```bash
cd ycg-project/backend
pip install -r requirements.txt
cp .env.example .env        # 编辑 .env 填入数据库配置（可选）
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

API 文档：`http://127.0.0.1:8000/docs`

### 前端启动

```bash
cd ycg-project/frontend
npm install
cp .env.example .env        # 编辑 .env 填入后端地址
npm run dev:mp-weixin
```

微信开发者工具导入 `dist/dev/mp-weixin` 目录。

### 爬虫启动（可选）

```bash
cd ycg-project/crawler
py -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
.\.venv\Scripts\python.exe -m playwright install chromium
cp .env.example .env        # 编辑 .env 填入 MySQL 配置
.\.venv\Scripts\python.exe -m jobs.init_schema
# 运行爬虫采集数据
.\.venv\Scripts\python.exe -m jobs.run_crawler
```

### cpolar 内网穿透（真机预览用）

```bash
# 在后端目录下新开终端
cd ycg-project/backend
cpolar http 8000
# 获取公网 URL 后更新前端 .env 并重新编译
```

完整的启动流程、配置细节和故障排查详见[项目最终对接记录文档](项目最终对接记录文档.md)。

## 配置说明

三个子项目均提供 `.env.example` 环境变量模板文件，使用时复制为 `.env` 并填入实际值：

| 文件 | 需要配置的内容 |
|------|---------------|
| `frontend/.env.example` | 后端 API 地址（本地/局域网/cpolar） |
| `backend/.env.example` | MySQL 连接信息 + 微信 AppID/Secret |
| `crawler/.env.example` | MySQL 连接信息 + 爬虫行为参数 |

**重要**：`.env` 文件包含敏感信息（密钥、密码等），已通过 `.gitignore` 排除，**不会提交到仓库**。仓库中仅保留 `.env.example` 模板文件。

## 前端功能展示

### 首页
- 顶部搜索栏（支持关键词输入和热搜词提示）
- 商品分类标签栏（横向滑动切换品类）
- 推荐商品瀑布流（优先展示跨平台比价商品，支持下拉刷新）

### 商品搜索与结果
- 支持按商品名称模糊搜索
- 搜索结果支持按价格升序/降序、销量排序
- 商品卡片展示最低价、平台标签、价格差

### 商品详情与比价
- 商品图片与基本信息
- 多平台比价卡片：每个平台一张卡片，清晰展示平台名、当前价、原价、折扣、店铺、销量
- 最低价卡片有"最优价"角标
- 支持收藏商品、设置降价提醒、复制商品链接

### 用户中心
- 微信昵称与头像展示
- 收藏数/浏览历史数/降价提醒数统计卡片
- 登录/退出功能

### 收藏与历史
- 收藏列表：已收藏商品管理，支持取消收藏
- 浏览历史：自动记录浏览过的商品，按时间倒序展示（刚刚/N分钟前/N小时前/N天前/具体日期时间）

### 降价提醒
- 为目标商品设置期望价格
- 系统自动比较当前价格与目标价格，达标时标记提醒
