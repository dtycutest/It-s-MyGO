# "一次买够"网购比价平台 - 项目文档汇总

## 📋 项目概述

**项目名称**：一次买够网购比价平台  
**项目类型**：微信小程序 + 后端API  
**开发周期**：14周  
**核心价值**：一次搜索，全面比价，一键购买

### 🎯 项目目标
解决用户在多个电商平台间反复切换比价的痛点，提供一站式商品比价服务，聚合淘宝、京东等主流电商平台的实时价格信息。

### 🛠️ 技术栈
- **前端**：微信小程序 (uni-app + Vue 3)
- **后端**：Python Django + MySQL/MongoDB
- **爬虫**：Scrapy框架
- **部署**：Docker + 云服务器

## 🚀 快速开始

### 1. 环境准备
```bash
# 安装依赖
npm install -g @vue/cli @vue/cli-service-global
npm install -g @dcloudio/uvm  # uni-app CLI
```

### 2. 项目初始化
```bash
# 克隆项目
cd It's Mygo-frontend
npm install

# 启动开发服务器
npm run dev
```
